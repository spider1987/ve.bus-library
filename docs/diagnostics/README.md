# Historische VE.Bus-Diagnose

`vebus-passive-capture.txt` ist ein passiver Rohmitschnitt mit Zeitstempeln
seit dem damaligen Start. Er dient der Protokollanalyse, nicht als aktueller
Gerätestatus.

`vebus-pinout.png` ist eine während der Diagnose verwendete Abbildung.
Sie ist kein verifizierter Verdrahtungsplan für jede Hardwarevariante.
Für die konkrete Verdrahtung gelten die geprüften Herstellerunterlagen.
